📱 1. Formato Escolhido e Justificativa Metodológica

Para as reuniões diárias da Sprint 1, adotou-se o formato de Daily Scrum Assíncrona em Canal Dedicado de Texto no Discord. Cada papel responde diariamente até as 11:00h às 3 perguntas fundamentais:

  1. O que fiz ontem desde a última reunião?
  2. O que farei hoje?
  3. Existe algum impedimento bloqueando minhas atividades?

Justificativa: Formato consolidado em Engenharia de Software para times distribuídos, permitindo rastreabilidade assíncrona completa, ausência de gargalos de comunicação e registro contínuo para auditoria acadêmica.
