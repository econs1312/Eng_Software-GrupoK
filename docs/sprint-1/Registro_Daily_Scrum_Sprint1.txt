1. FORMATO ESCOLHIDO PARA AS REUNIÕES DIÁRIAS
--------------------------------------------------------------------------------
Formato: Daily Scrum Assíncrona via Canal de Texto no Discord (#daily-scrum-grupo-k)
Timebox/Horário Limite: Diariamente até as 11:00h da manhã.

Justificativa Técnica:
A simulação adota o formato assíncrono por ser o padrão de excelência na indústria
global de Engenharia de Software para times distribuídos. Cada papel responde
diariamente às 3 perguntas canônicas do Scrum, assegurando visibilidade transparente,
histórico para auditoria e rapidez na mitigação de impedimentos.
