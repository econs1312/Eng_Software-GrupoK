## 🚀 Como Visualizar e Ler a HQ

A equipe disponibilizou três formas complementares de leitura da obra:

1. 🌐 **Leitor Web Interativo (Web Comic Reader):**  
   Abra o arquivo [`hq/index.html`](index.html) no navegador para ler em modo **Webtoon contínuo** ou **Modo Cinema (Slide painel por painel)**, com visual cyberpunk, notas técnicas de Engenharia de Software e diálogos destacados.

2. 📖 **Versão para Impressão Diagramada (A4):**  
   Abra o arquivo [`hq/comic_book_completo.html`](comic_book_completo.html) para visualizar a edição em formato revista tradicional com 6 páginas.

3. 📥 **Compilação Oficial em PDF (Alta Resolução):**  
   Baixe ou visualize o arquivo compilado em:  
   👉 [`hq/pdf/Debugando_o_Futuro_HQ_GrupoK.pdf`](pdf/Debugando_o_Futuro_HQ_GrupoK.pdf) (Documento oficial para avaliação acadêmica no AVA).

## 🎨 Especificações Técnicas das Imagens

- **Resolução:** Alta definição para visualização digital e impressão (300 DPI equivalente).
